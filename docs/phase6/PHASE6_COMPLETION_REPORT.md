## 3. Model performance (unchanged by Phase 6; out-of-sample, participant-grouped)
Default dashboard model (sensor-only random forest, 3 s horizon): average precision 0.134 (prevalence 0.062), event sensitivity
0.21 (16/75, 95 % CI 0.04-0.35), 74.3 false alerts/hour (CI 24.2-123.9) against a 30/h threshold-selection budget, median lead
1.65 s. Clinical + sensor fusion: no distinguishable difference. Dashboard replays are in-sample demonstrations. Phase 6 did not
and could not improve these results; it made them reproducible and visible.

## 5. Known limitations of the release itself
Replays of dataset recordings are in-sample; 22 participants; weak sensitivity and frequent false alerts; scores uncalibrated;
some recordings give no forecast; `persist_state=true` is optional and never overwrites an existing twin; versions newer than the
lock file load the saved models with a scikit-learn warning.
